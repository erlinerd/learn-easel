SOUL.md 与四层提示词栈：常驻层为什么必须短

45 min · 精读 SOUL.md(31行) + docs/prompt-stack.md

🎒 预备知识：完成上一课「L03」（零基础入口：第 0 课）

本课唯一结论：提示词栈的每一层都遵循一个铁律——常驻的越少越好，按需的越多越好。 SOUL.md 里每一处"刻意不写"都是把 token 和时效性让给正确的层。

一、基础：人格层为什么存在（而不只是规则层）

一个自然的疑问：AGENTS.md 已经有六条规则了，为什么还要一份 SOUL.md？ 因为规则管不了规则没写到的事。规则是枚举："不要泄露密钥"——但模型每天面对 无数规则没枚举的情境（用户让它写一篇"介绍我的 AI 助手"的文案，要不要提工具名？）。 人格的作用是提供默认倾向：SOUL 里一句"对外文案绝不暴露任何工具或配置痕迹…… 你是创作者的搭子，不是在给系统打广告"，让模型在规则未覆盖的情境里也有正确的直觉。 这对应 L5 的能力认知：模型是模式补全机——人格就是给它植入一组默认模式， 比枚举所有情况便宜得多。

二、四层栈回顾 + 每层的"不许越界"

层写什么刻意不写什么（本课考点）
SOUL.md 人格搭子语气、能力总览（类目级）、沟通风格① 不写具体 skill 名——会过时（weibo 教训）；② 不写"去调某某 skill"的操作机制——那是 AGENTS 的事
AGENTS.md 规则六条规则、五层分工、编排、边界不承载人格语气；规则不带情绪
CONTEXT.md 路径sync.sh 自动生成的项目绝对路径手工不编辑——换机器重跑 sync 即新
SKILL 按需流程、约束、边界（<200 行）不常驻；不用的不加载

"不越界"不是洁癖。每层的内容有不同的变化频率：人格（年级别稳定）→ 规则 （月级别）→ 路径（机器级别）→ 技能（周级别）。变化快的进常驻 = 缓存全废（L2 复利账单 + A5 稳定前缀）；写错层 = 维护时找不着北。分层 = 按变化频率和加载时机切分职责。

三、SOUL.md 逐句精读（31 行里的关键句）

"先想怎么帮他做成，而不是'这个我做不了'"（:16）——人格层的总纲。 这不是鸡汤：执行型 agent 最常见的失效模式是模型诉苦式拒答（"作为 AI 我无法……"）。 这句把默认倾向扭向"想办法"。

"先去技能库找对应的 SKILL 照着用，别凭记忆裸做；……（具体规则见 AGENTS。）"（:18）—— 最值得学的一句：人格层只给动机，机制细节显式指路给 AGENTS。 括号里那句"见 AGENTS"就是层间边界的活例子——SOUL 不复述 AGENTS 的路由规则， 避免同一条规则写两处（两处必漂移，L03 的单一真相源精神）。

"问到'我的账号/我的帖子/我的粉丝/最近发了啥'这类，先去查已登录账号和站内数据， 别回头问他要账号名。"（:21）——等等，这不是和 AGENTS 规则④"查现有信息再提问"重复了吗？ 不是重复，是场景化重申：规则④是抽象原则，这句是最高频场景的直给。 prompt 工程里关键规则"一次抽象 + 一次具体"是合理冗余——模型对具体例子的命中率远高于抽象原则（L5 ICL）。

"发出去的东西只谈内容本身：对外文案/评论绝不暴露任何工具或配置痕迹……"（:30）—— 人格化表达的安全规则，与 content_guard（L14）形成两层：闸门是确定性硬拦（密钥/内网）， 人格是概率性直觉（"不要给系统打广告"的自曝倾向）。两层缺一不可——闸门管枚举的，人格管没枚举的。

四、常驻层短的第二个理由：prompt cache（数字版）

L2/A5 讲过原理，这里算一笔 Easel 的实际账：SOUL 31 行 + AGENTS 111 行 + CONTEXT ≈ 常驻 4–5K token。如果命中缓存，这部分每轮成本约 1/10；如果每次内容有变（比如把 "当前热门话题"写进 SOUL），每轮全价 + 前缀重建。OpenClaw 源码把这件事写成了 军规级注释（system-prompt.ts:1146）："Approval UI and owner identity vary by turn, so keep both below the stable prefix"——可变内容必须排在稳定边界之后（正课 L16 站 4 会读到）。

五、常见踩坑

坑 1：人格层写成能力清单。列 50 个技能名——必过时（weibo 教训：技能改名后 人格层还在教模型调旧名）。保持类目级："做视频（AI 生成、剪辑、切片……）"这样按能力类写。
坑 2：两层写同一规则。AGENTS 写了路由规则，SOUL 再详细抄一遍——漂移隐患； 正确姿势是 SOUL 给动机 + 指路。
坑 3：把 SOUL 当 system prompt 垃圾场。临时需求、活动公告全塞进去—— 常驻层只放"每一轮都成立"的东西，这是 A5 的判断标准。
