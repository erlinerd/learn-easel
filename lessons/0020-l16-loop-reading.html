hasMoreToolCalls =

① continuationRequired：流式层判定"模型还有没说完的工具调用"—— 流可能分多段吐 tool calls，这段没完就得继续。
② stop 且 endTurn === false：模型说"stop"但显式标记"话没说完" （Responses API 的续跑语义）——即使看起来停了也不终止。
③ 批次未终止：刚执行的这批工具没有被钩子/准入标记 terminate—— 只要没被叫停且确实有批次在跑，就再给模型一轮。
三项任一为真就继续内层循环；全假才出循环走 followUp 队列 → agent_end。
